# AccommoSeek

AccommoSeek is a full-stack hotel recommendation system designed to help users find hotels based on various filtering criteria. The system utilizes real-world datasets, advanced database normalization techniques, and a modern web stack to provide an efficient and insightful recommendation experience.

## Features
- **Hotel Filtering:** Users can search for hotels based on keywords and historical data, including crime rate, weather, living wage, and ratings.
- **Real-World Data Integration:** The system imports and processes real-world datasets to create meaningful database relationships.
- **Optimized Database Design:** Utilizes MySQL with 3NF normalization to ensure data integrity and efficiency.
- **Frontend & Backend API Communication:** Implements RESTful APIs to facilitate interaction between the frontend (Next.js) and backend (Django).
- **Database Management:** Utilizes MySQL CRUD operations, triggers, and stored procedures to manage data effectively.

## Technologies Used
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** MySQL
